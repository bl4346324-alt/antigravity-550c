# Antigravity 皮肤中心 (DSH Skin Center)

基于 DeepSeek Harness (`github.com/zhu1090093659/dsh-skins`) 架构打造的 Antigravity 动态视频壁纸与毛玻璃主题引擎。

## 快速控制入口

直接在 Antigravity 侧边栏（辅助窗格 Aux Pane）或浏览器中打开皮肤中心：
- [🎨 打开 DSH 皮肤与壁纸中心 (Aux Pane)](sidecar://antigravity-550c/controller/)
- [🌐 浏览器本地控制台 (http://127.0.0.1:5566)](http://127.0.0.1:5566)
- [⚙️ 管理插件配置](customization://antigravity-550c)

## 内置主题风格 (Skin Catalog)

1. **🌌 蔚蓝幻想 (Blue Fantasy)**：DeepSeek Harness 经典旗舰主题，鲸落星海与深蓝流光，极客微透毛玻璃质感。
2. **💎 晶莹琉璃 (Crystal Frosted)**：Aero 晶莹冰晶毛玻璃，半透明轻透高光与胶囊药丸按钮（完美对齐参考图质感）。
3. **🐋 深海之歌 (Whale Song)**：塞壬空灵微光，碧蓝水波与深海青透毛玻璃。
4. **🌑 黑曜极客 (Obsidian Dark)**：Codex / OLED 极夜微透黑曜石，高对比度护眼。

## 核心控制功能

- **动态视频背景**：2K 60fps NASA 深空星系流光，支持自定义本地视频文件或网络直链。
- **背景遮罩 (Scrim)**：独立对比度遮罩层，防止背景星空干扰正文与代码阅读。
- **毛玻璃与透明度微调**：高斯模糊 (0~30px)、侧边栏通透度、胶囊输入框毛玻璃强度、气泡透明度实时热调节。
- **免刷新实时切换**：支持实时预览与一键启用，无需重启客户端。
